One funny line from a lighthouse night shift, told as a tiny story with a punchline: the ships never come, the seagulls have unionized, and last week the fog filed a noise complaint against the light itself.

> I work nights at a lighthouse. The ships never come, the seagulls unionized, and last week the fog filed a noise complaint against the light.

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, exactly one line, built as three escalating beats with the laugh landing on the last word.

```sh
python3 main.py
```
